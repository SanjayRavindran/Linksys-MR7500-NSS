# Linksys MR7500 (Hydra Pro 6E) — Monthly Firmware Update & Sysupgrade Guide

This runbook is a step-by-step guide to updating your Linksys MR7500 router each month using the automated private builds generated by GitHub Actions.

---

## Quick Reference Summary

| Property | Details |
|---|---|
| **Pipeline Schedule** | 1st of every month at `00:00 UTC` (`cron: '0 0 1 * *'`) |
| **Manual Trigger** | GitHub Web UI → **Actions** → **Build Monthly Snapshot Firmware (Private)** → **Run workflow** |
| **Included Variants** | Both **`router-mode/`** (`10.143.1.1/24`) and **`switch-ap-mode/`** (`192.168.1.91/24`, 5-port bridge) |
| **Mode Switcher** | `/usr/sbin/switch_mode [router|ap]` pre-installed on device |
| **Current AP IP** | `https://192.168.1.91/` (Switch + AP Mode) |
| **Fallback IP** | `https://10.143.1.1/` (Router Mode / VM Access) |

## Step 1: Download the Private Monthly Build

Because the firmware includes proprietary vendor blobs (Marvell AQR114C PHY firmware and Qualcomm NSS microcode), compiled binary images are kept strictly private to your GitHub account:

1. Open your GitHub repository:
   👉 **[https://github.com/SanjayRavindran/Linksys-MR7500-NSS](https://github.com/SanjayRavindran/Linksys-MR7500-NSS)**
2. Navigate to the **Actions** tab:
   👉 **[https://github.com/SanjayRavindran/Linksys-MR7500-NSS/actions](https://github.com/SanjayRavindran/Linksys-MR7500-NSS/actions)**
3. Select the latest successful run of **Build Monthly Snapshot Firmware (Private)**.
4. Scroll down to the **Artifacts** section at the bottom of the page.
5. Click **`mr7500-firmware-YYYYMMDD`** to download the zip archive.
   *(Alternatively, check the **Releases** tab for your private **Draft Release**).*

---

## Step 2: Unpack and Verify Checksums

Open a terminal (PowerShell, WSL, or Linux shell) in the folder where you downloaded the file:

```bash
# 1. Unzip the downloaded workflow artifact
unzip mr7500-firmware-*.zip

# 2. If GPG encryption was configured:
gpg -d mr7500-openwrt-nss-*.tar.gz.gpg | tar -xz

# 3. If unencrypted:
tar -xzvf mr7500-openwrt-nss-*.tar.gz

# 4. Verify cryptographic SHA-256 integrity
sha256sum -c sha256sums.txt
```

You should see:
```text
openwrt-qualcommax-ipq60xx-linksys_mr7500-initramfs-uImage.itb: OK
openwrt-qualcommax-ipq60xx-linksys_mr7500-squashfs-factory.bin: OK
openwrt-qualcommax-ipq60xx-linksys_mr7500-squashfs-sysupgrade.bin: OK
```

## Step 3: Flash Firmware to the Router

Every private release archive bundles **both** configuration variants plus an interactive Ubuntu 24.04 / 26.04 TFTP flasher:
* `router-mode/` — Default NAT Router (`10.143.1.1/24`, WAN DHCP client, LAN DHCPv4 + SLAAC).
* `switch-ap-mode/` — Your current Switch + AP config (`192.168.1.91/24`, all 5 ports bridged, DHCP disabled).
* `flash_mr7500_tftp_ubuntu.sh` — Ubuntu 24.04 / 26.04 TFTP + HTTP flash utility.

### Option TFTP (Ubuntu 24.04 / 26.04 Recovery or Fresh Install):
```bash
# Flash Switch+AP build (or pass --variant router):
sudo ./flash_mr7500_tftp_ubuntu.sh --variant switch-ap

# Or test in RAM only without modifying NAND:
sudo ./flash_mr7500_tftp_ubuntu.sh --variant router --mode ramboot
```

### Option Sysupgrade (Existing OpenWrt Router):

You only need `openwrt-qualcommax-ipq60xx-linksys_mr7500-squashfs-sysupgrade.bin`.

### Option A: Via LuCI Web Interface (Recommended)
1. Open your browser:
   * If currently in **Switch + AP Mode**: `https://192.168.1.91/`
   * If currently in **Router Mode**: `https://10.143.1.1/`
2. Log in as `root`.
3. Navigate to: **System** → **Backup / Flash Firmware**.
4. Under **Flash new firmware image**, click **Flash image...**.
5. Select `openwrt-qualcommax-ipq60xx-linksys_mr7500-squashfs-sysupgrade.bin`.
6. Choose whether to:
   * **Keep settings (checked):** Retains your current network mode, Wi-Fi keys, and passwords.
   * **Clean install (unchecked):** Resets to default factory Router Mode (`10.143.1.1/24`).
7. Click **Continue** to start flashing.
8. Wait ~90 seconds for the router to flash NAND Slot 1 and reboot.

---

### Option B: Via SSH Command Line
Transfer the sysupgrade image directly to `/tmp` on the router:

```bash
# From Windows / Linux PC:
# If in Switch + AP mode (IP 192.168.1.91):
scp openwrt-qualcommax-ipq60xx-linksys_mr7500-squashfs-sysupgrade.bin root@192.168.1.91:/tmp/sysupgrade.bin
ssh root@192.168.1.91

# Or if in Router mode (IP 10.143.1.1):
scp openwrt-qualcommax-ipq60xx-linksys_mr7500-squashfs-sysupgrade.bin root@10.143.1.1:/tmp/sysupgrade.bin
ssh root@10.143.1.1
```

Once logged into the router shell:
```bash
# To preserve current settings:
sysupgrade -v /tmp/sysupgrade.bin

# Or to perform a fresh clean install (restores default Router Mode):
sysupgrade -n -v /tmp/sysupgrade.bin
```

## Step 4: Operating Mode Adjustment (If Needed)

> [!NOTE]
> Every compiled image defaults to **Router Mode** (`10.143.1.1/24`, NAT on WAN, DHCP server on LAN).
> If you flashed with `sysupgrade -n` (clean install), the router will revert to Router Mode at `10.143.1.1`.

If you use the router as a **Dumb AP / Unified 5-Port Switch + Wi-Fi 6E AP**, simply run the bundled mode switcher:

```bash
# SSH into router (connect to 10.143.1.1 if clean flashed, or 192.168.1.91 if settings preserved):
ssh root@10.143.1.1

# Switch to Switch + AP mode (assigning static IP 192.168.1.91 on main LAN):
/usr/sbin/switch_mode ap 192.168.1.91
```

To switch back to **Router Mode** at any time:
```bash
/usr/sbin/switch_mode router
```

## Step 5: Post-Upgrade Health Check & Verification

Run the automated validation suites to ensure all 14 hardware subsystems, NSS acceleration flows, and Wi-Fi 6E radios are working at 100%:

### 1. Remote Python Test Suite (from Windows PC):
```bash
# In Switch + AP mode:
python tests/test_mr7500_validation.py --host 192.168.1.91

# In Router mode:
python tests/test_mr7500_validation.py --host 10.143.1.1
```

### 2. On-Device Shell Health Check:
```bash
ssh root@192.168.1.91 "sh -s" < scripts/validate_firmware.sh
```

**Expected Results:**
- `TC-01`: Boot Slot 1 Active (`boot_part=1`) & OEM Slot 2 intact: `PASS`
- `TC-02`: Linux 6.12 Quad-Core 1.8 GHz Performance Governor: `PASS`
- `TC-03`: Qualcomm NSS Ubi Core 0 & ECM Engine: `PASS`
- `TC-04`: Marvell AQR114C 5GbE WAN Link & USXGMII in-band: `PASS`
- `TC-05`: QCA8075 4-port Gigabit LAN Switch: `PASS`
- `TC-09`: Tri-Band Wi-Fi 6E (2.4G / 5G / 6G 160MHz) & ath11k: `PASS`
- `TC-10`: USB 3.0 DWC3 SuperSpeed Host: `PASS`
- `TC-12`: CSR8811 Bluetooth Standby (GPIO 34 low): `PASS`
- `TC-13`: Qualcomm NSS Hardware Accelerated Flows: `PASS`
- `TC-14`: NSS & Wi-Fi IRQ Affinity Pinning (off CPU 0): `PASS`

## Emergency Rollback to Stock Firmware (Slot 2)

If a build fails to boot or you need to return to OEM factory firmware:
1. The Linksys MR7500 has a safe dual-slot NAND partition table. OEM firmware is permanently preserved in **Slot 2** (`alt_kernel` and `alt_rootfs`).
2. **Auto-Recovery:** If OpenWrt fails to boot 3 consecutive times, U-Boot automatically fails over to Slot 2.
3. **Manual Rollback:** Power-cycle the router 3 times rapidly (turn off switch as soon as LEDs light up, wait 3 seconds, turn back on). U-Boot's boot counter will switch `boot_part` from `1` to `2`.
